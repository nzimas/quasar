Other projects

Firmware and instruments by Nuno Zimas for other hardware. Source code of each is on GitHub.

Bigorna

M-VAVE FM-1

FM-1 firmware for rhythmic noise, power noise, power electronics and IDM, after Elektron Digitone II: 6 tracks, 4 machines, Digitone II's page layout, parameter locks, looper and send effects. Quasar's control layer — sequencer, patterns, sessions, MIDI — comes from it. Installed from browser.

Website GitHub repository

Tonitor

M-VAVE FM-1

Acousmatic firmware for FM-1, for electroacoustic experimentation, live ambient music and sound exploration. Not groovebox: 7 engines, free-running loopers and generative sequencers. Installed from browser, as Quasar is.

Website GitHub repository

Motor:Cycles

Elektron Model:Cycles

Firmware for rhythmic noise and power noise. Generative algorithms build sounds, kits, phrases and patterns, with one control for how complex and dense result is; Model:Cycles' own functions stay available. Based on official OS 1.13 and installed with browser patcher that modifies your own copy of official firmware.

Website GitHub repository

DigiRust

Elektron Digitone II

Firmware tools for IDM, rhythmic noise and power noise, and electroacoustic music: browser patcher and macOS app that create modified copy of official Digitone II OS on your computer. No Elektron firmware is distributed. For Digitone II only.

Website GitHub repository

PoundHard

Ableton Move

16-track groovebox for IDM, rhythmic noise and percussion-based experimental electronic music. SuperCollider engine does sound, Python controller holds musical state, and Move's pads, buttons, encoders and screen are interface. 2 editions:

  • Armbian editionCurrent

    Runs on Armbian with real-time kernel, in place of Ableton's software; started from menu on Move's screen.

    GitHub repository
  • Schwung editionNo longer updated

    Runs alongside Move's own software, as Schwung takeover module.

    GitHub repository

Granola

macOS · Ableton Move · Akai MPC One

Multitrack granular synthesizer: each track reads sample as material for grain clouds around playhead moved by hand. 3 versions, for different hardware:

  • Granola for macOS

    Eight tracks, played from M-VAVE SMC-Mixer and SMC-Pad Pocket. SuperCollider's audio server is built into app; 154 Airwindows effects, reverb and delay.

    Downloads GitHub repository
  • Granola for Move

    Eight tracks on Ableton Move, as Schwung takeover module, with macOS version's sound engine. Includes sample harvester.

    GitHub repository
  • Granola MPC

    5 tracks on Akai MPC One (1st generation), on OpenMPC environment in place of stock application. Filters, 9 LFOs per track, parameter-lock pads and gesture loops.

    GitHub repository
