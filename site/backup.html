Back up sessions

This page copies sessions stored on FM-1 running Quasar — each with its patterns and loops — and GLOBAL SETUP settings (MIDI, MIDI LEARN) to file on this computer, and puts them back from that file. Use it before you install another firmware (it may erase or overwrite them): when you reinstall Quasar, restore file here. It works in desktop Chrome, Edge or Opera, over USB MIDI, and needs Quasar on FM-1. Nothing is uploaded anywhere: file stays on this computer.

Not connected

Connect FM-1 with USB data cable, switch it on, then find it.

In file
no file opened

Restore

Open backup file, then write it to FM-1. Every session in file replaces one in same slot on FM-1, with its patterns and loops; GLOBAL SETUP is replaced if file holds it. Other sessions on FM-1 are kept.

Notes

  • Close any other program using MIDI (DAW, M-VAVE's app), and allow MIDI access when browser asks: sessions travel as MIDI system-exclusive messages.
  • FM-1 keeps playing while this page works, but writing to its flash silences audio for a moment each time.
  • Each part is copied whole and checked before it is written: one that does not arrive intact is not written. Session's loops are written before session, so restore cut off leaves that session as it was.
  • Session playing on FM-1 is not changed by restore: load it again (SHIFT + SAVE, then its white key) to hear what was restored. Save it first if it has changes you want to keep.

Page (js/backup.js) and part of firmware that answers it (firmware/src/backup.c) are GPL-3.0, on GitHub. They follow Bigorna's and Tonitor's backup page.
